## Problem

After upgrading every package (FUR-0004), new releases of Next.js, React,
Tailwind CSS, TypeScript and Playwright may offer features that improve the
site: e.g. React 19 `<ViewTransition>` / Activity, Next.js Cache Components
and `use cache`, newer Tailwind v4 utilities, Playwright features for
visual testing.
